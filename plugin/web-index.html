核心功能

  • 创建、编辑思维导图
  • 拖拽调整节点位置
  • 多种主题和布局
  • 节点样式自定义
  • 导入/导出多种格式

使用说明

  • 双击节点编辑文本
  • 右键节点查看更多操作
  • 使用工具栏调整样式
  • 拖拽节点调整层级
  • Ctrl+Z 撤销操作

快捷键

  • Enter: 添加同级节点
  • Tab: 添加子节点
  • Delete: 删除节点
  • Ctrl+S: 保存
  • Ctrl+E: 导出
